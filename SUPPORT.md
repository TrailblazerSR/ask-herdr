# Support

Ask-Herdr is a Git-installable developer preview with best-effort community
support. It is not a package-registry release, hosted service, managed
deployment, or compatibility-guaranteed product.

Public issues may cover reproducible behavior using synthetic data, public
schema questions, and documentation defects. Do not post Project bindings,
request JSON, validation output, credentials, private paths, provider output,
or security-sensitive details. Follow [SECURITY.md](SECURITY.md) for private
vulnerability reports.

Python 3.10 or later is required. macOS and Linux provide the full local route,
WSL follows the Linux profile, and native Windows provides contract discovery
and bundled schemas only. A real status observation additionally requires an
already-bound Project root and matching Authority UUID supplied by that
Project's owner. The repository does not provide Project onboarding or binding
discovery.
